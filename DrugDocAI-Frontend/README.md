# DrugDoc AI Frontend

Clean rebuild of the DrugDoc AI frontend.

## Stack
- React
- TypeScript
- Vite
- Lucide React
- Motion
- React Router

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Current milestone

F01 landing page + foundational visual system.

Next screens:
F02 Drug & Mode Selection
F03 Ask Question
F04 Answer / Results
F05 Source Viewer
F06 High-Risk Escalation
F07 Low Confidence
Then the Admin workflow.

## Design direction

Deep teal + botanical green + healing clay + warm ivory + restrained citrus highlights.

No unrelated AI robots or mascots. Decorative visuals must relate to medication, medical documentation, safety, healthcare, or wellbeing.
